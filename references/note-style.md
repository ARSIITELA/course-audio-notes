# 课程笔记风格规范（默认风格）

本文件是一套经过实际验证的课程录音笔记默认风格。优先级：用户明确要求 > 用户已有历史笔记的风格 > 本文件。整理前先确认用户有没有自己的历史笔记或风格要求，没有再按本文件执行。

## 目录

1. 整体结构
2. 语言风格
3. 标记体系
4. 板块如何组织
5. 金句怎么写
6. 转写纠错与模糊处理
7. 完整结构模板

## 整体结构

```
# <课程名>第X天（或第X讲）笔记

> 今日核心：一段话（200-400字），按"上午/下午/晚上"或主题顺序，
> 把全天讲了什么、最关键的结论、当天作业串成一段，不分行。

---

## 板块一标题（内容自然命名，不带序号）
- 要点……
- 要点……

ps：个人批注。

---

## 【重点案例】XX案例
（案例正文）

---

## 今日作业
1. ……

---

## 核心金句
1. ……
2. ……
```

- 一级标题只有文件顶部一个（`#`）。
- 板块全部用 `##`，板块之间用 `---` 分隔。
- 板块内子层级用 `###` 或加粗短句，不超过三层。

## 语言风格

1. **句子直接省力**。直接说结论，不加帽子、对比、铺垫。
   - 弱："过程比结果更有意思，值得注意的是我们可以看到……"
   - 强："关键在第二步，第一步只是准备。"
2. **要点式 + 口语化**，保留讲课的语气和原话味道，不写成书面报告。
3. 同一意思不反复铺垫，一个板块讲清一件事。
4. 保留有信息量的口头表达、口头禅式金句，不擅自规范化。
5. 笔记是给学员复习和应对考核/面试用的，每个板块要能回答"这块在考试/实际工作里怎么用"。

## 标记体系

| 标记 | 用途 | 示例 |
|---|---|---|
| `ps：` | 自己的批注、补充、记忆提示，独立成段或板块末尾 | `ps：这和第一讲讲过的X是同一件事，可以串起来记。` |
| `【XX案例】` | 板块标题里的重点案例 | `## 【重点案例】XX产品怎么设计用户记忆` |
| `【案例】` | 行内小案例 | `【浇花案例】保洁阿姨把不能浇水的盆景浇死了……` |
| `【面试题】` / `【面试视角】` / `必背` | 考核/面试直接可用的内容 | `**【面试题】讲方案之前先说用户是谁。**` |
| **加粗** | 关键结论、定义、必须背的句子 | `**定义八个字：自主决策、自主调用。**` |
| 表格 | 有 2 个以上维度的对比（形态演进、类型对比、用户分层） | 见各天笔记 |
| 有序列表 | 有严格顺序的流程、步骤 | 操作流程、方法步骤 |
| 无序列表 | 并列要点 | 常规要点 |

课程没有面试/考核属性时，把 `【面试题】` 换成 `【实操要点】`/`【工作用法】` 等符合受众的标记。

## 板块如何组织

- **不按录音文件分段概括**。先把全天内容按主题归类，同一主题跨多段录音要合并成一个板块。
- 板块标题写内容本身，不写"上午第一部分""录音一"。
- 一天通常 15-25 个板块，按内容多少自然决定，不强求数量。
- 典型板块顺序（按实际内容裁剪）：
  - 概念/定义类（是什么、和易混概念的区别）
  - 核心案例拆解（信息量大，单独成板块）
  - 流程/方法/操作类（步骤、铁律、清单）
  - 对比与分层（用表格）
  - 行业认知/数据/谈资
  - 实操演示、工具、协作规范
  - 角色认知、职业发展、嘉宾分享
  - 今日作业/课后任务
  - 核心金句
- 案例的处理：讲清楚"背景→做法→为什么→结论"，老师举的真实公司、产品、数字、金额保留。
- 一个板块讲一个完整主题；内容太满就拆成两个板块。

## 金句怎么写

- 固定在文末"## 核心金句"，10-18 条，编号列表。
- 选讲课原话中**有观点、可复用、考核/面试能直接说**的句子；优先选有冲突感、有记忆点的。
- 每条一句话，不超过 50 字，保留口语味道。
- 金句不要和正文要点机械重复，选最"扎心"的。
- 课程没有明确金句时，可改为"## 关键结论"，保留相同写法。

## 作业板块

- 老师当天布置的作业、测试题、课后任务、要交的交付物，单独成"## 今日作业"（或"## 本讲任务"），用有序列表写清要求、场景、交付物、截止时间。
- 讲座、班会、提醒事项等放作业板块末尾。

## 转写纠错与模糊处理

转写稿是口语识别结果，先做术语还原，再写笔记。原则：

- 领域术语、产品名、人名、公司名，按该课程的真实用语还原；不确定的用"课堂音记XX"标注。
- 完全无法还原的词，保留口语描述并在最终回复的"模糊处理项"列出。
- 不编造数据补齐录音缺口。

下表是某次 AI 产品经理课程的音近错词还原示例，仅作方法演示；处理其他课程时按课程领域重建此表：

| 转写（音近） | 正确 |
|---|---|
| 英文术语被读成近音词（如 cooperate） | Copilot |
| 英文短语被整句音译（如"human路"） | Human in Loop（人工在环验证） |
| 产品名音近（如 work badly） | 真实产品名 WorkBuddy |
| 中文公司名音近（如"八朵火锅"） | 巴奴火锅 |
| 人名/播客音近（如"张小军博客"） | 张小珺商业访谈录（播客） |
| 招聘系统音近（如"北森跟猫卡"） | 北森、Moka |
| 职级口语（如"加一/加二"） | +1 直属领导 / +2 上级的上级 |
